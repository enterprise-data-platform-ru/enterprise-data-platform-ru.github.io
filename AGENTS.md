# Enterprise Data Platform — контекст проекта

## Цель
Развивать корпоративный сайт enterprisedataplatform.ru: архитектура платформы данных, технологии, документация и в будущем подтверждённые услуги.

## Стек и ограничения
- Next.js App Router, React, JavaScript ESM, обычный CSS, статический экспорт (`output: 'export'`).
- Не добавлять SSR, API routes, внешние SDK, Tailwind или Nextra без отдельного задания.
- Server Components по умолчанию; client components только при необходимости.
- Тексты хранить в `src/content/site.mjs`; секции отдельно в `src/components/`.
- Не копировать тексты, логотипы и графику референсов. Не выдумывать клиентов, метрики, SLA, сертификаты, партнёрства, email.
- Адаптивность 360–1440 px, доступная клавиатурная навигация, семантический HTML, русские тексты.
- Не использовать внешние шрифты и трекеры без согласования.

## Развёртывание
- Основной хостинг — GitHub Pages через `.github/workflows/ci.yml`. Публикуется только `out/`; серверного runtime нет.
- `NEXT_PUBLIC_BASE_PATH` задаётся в CI из `configure-pages`; на custom domain пуст, для project site равен пути репозитория. Для файлов `public/` используй `assetPath()` из `src/lib/paths.mjs`; для внутренних страниц — Next Link. Канонический домен сохраняй.
- После сборки запускай `npm run check:export`. Не добавляй API routes, SSR, server actions или секреты в клиентские переменные. Не меняй DNS, настройки репозитория и не выполняй push без явной задачи.
- Инструкция: `docs/GITHUB-PAGES.md`.

## Работа с небольшим контекстом
1. Прочитай этот файл и описание текущей задачи в `docs/ROADMAP.md`.
2. Сначала открой только релевантные файлы; используй поиск по именам и функциям. Не загружай весь репозиторий, `node_modules`, `.next`, `out`, `preview` или изображения.
3. Сформулируй план из 2–4 шагов. Меняй минимальный набор файлов, не переписывай проект целиком.
4. Выполни `npm test` и `npm run build` (если зависимости установлены). Не заявляй о проверках, которые не запускались.
5. Дай короткий отчёт: файлы, изменения, проверки, оставшиеся риски. Остановись после текущей задачи.

## Карта исходников
- `src/app/page.jsx`: сборка секций; `layout.jsx`: метаданные.
- `src/content/site.mjs`: единый источник текстового контента.
- `src/components/Header.jsx`, `Hero.jsx`, `Platform.jsx`, `Architecture.jsx`, `Solutions.jsx`, `Icon.jsx`.
- `src/app/globals.css`: дизайн-токены и адаптивность.
- `public/`: локальные ресурсы; `tests/`: тесты контента.
- `preview/`: снимок первой версии для просмотра, не редактировать как исходник.

## Визуальная система
Графитовый фон, лаймовый акцент, светлые информационные секции, инженерная моноширинная микро-типографика. Основной текст — системный sans-serif. Сохраняй контраст и не перегружай интерфейс декоративными эффектами.

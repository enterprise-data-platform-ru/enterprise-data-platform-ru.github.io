# Enterprise Data Platform

Стартовый русскоязычный лендинг для https://enterprisedataplatform.ru. Независимый архитектурный проект, а не заявление о наличии готового сертифицированного продукта.

## Быстрый просмотр

Откройте `preview/index.html` в браузере. Это автономный снимок страницы, созданный из тех же компонентов; он не требует Node.js. Для доработки используйте исходники, а не снимок.

## Разработка

Требуется Node.js 22+ и npm. В корне проекта:

```bash
npm install
npm test
npm run dev
```

Откройте http://localhost:3000. При первом успешном `npm install` зафиксируйте `package-lock.json` в Git. Для повторяемых сборок используйте `npm ci`.

```bash
npm run build
npm run preview
```

Next.js экспортирует сайт в `out/`. Это статические HTML/CSS/JS-файлы, размещаемые на Nginx, S3-совместимом хостинге или CDN. Никакого Node.js в production не требуется. `npm run preview` запускает локальный HTTP-сервер для `out/`.

## GitHub Pages (основной вариант публикации)

Подготовлен автоматический workflow `.github/workflows/ci.yml`: PR проверяет проект, push в main собирает и публикует `out/`. Включите **Settings → Pages → Source → GitHub Actions**, затем запустите workflow. Для своего домена и временного URL автоматически определяется `basePath`.

Полная инструкция: [GitHub Pages, DNS, HTTPS и откат](docs/GITHUB-PAGES.md).

### Docker (альтернативный вариант)

```bash
docker build -t edp-website:0.2 .
docker run --rm -p 8080:80 edp-website:0.2
```

Откройте http://localhost:8080. TLS настраивается на внешнем reverse proxy или ingress; конфигурация Nginx внутри контейнера обслуживает HTTP.

## Источники и подход

- https://github.com/axivo/website — архитектурный референс Next.js/React, компонентный подход, ориентация на документацию. AXIVO использует также Nextra, Tailwind и Cloudflare; в MVP эти зависимости намеренно не добавлены. Исходный код AXIVO не копировался.
- https://arenadata.tech/ru — референс структуры продуктового лендинга: компоненты, логическая схема, сценарии, FAQ. Тексты, визуальные материалы и бренд Arenadata не использованы.

## Перед публикацией

1. Подтвердить позиционирование, тексты, перечень реально доступных услуг и продуктов.
2. Настроить действующий email в `src/content/site.mjs` либо разработать серверную контактную форму; сейчас сбор данных отсутствует.
3. Проверить DNS/TLS, Open Graph и SEO; при включении форм или аналитики подготовить применимые юридические документы и согласия.
4. Выполнить `npm install`, `npm test`, `npm run build`, проверить собранный `out/` в браузере. Зависимости npm не были доступны в среде подготовки; фактическая сборка Next.js не подтверждена. Автономный снимок и тесты контента проверяются отдельно.

Нет внешних шрифтов, аналитики, трекеров, сторонних CDN, вымышленных кейсов клиентов или сертификатов. Названия open-source технологий приведены как возможные компоненты; это не подтверждение партнёрства.

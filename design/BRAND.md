# Enterprise Data Platform — правила оформления v1.0

Источник: CSS и компоненты сайта enterprisedataplatform.ru. Правила печатных материалов и минимальные размеры являются предложением для утверждения владельцем.

- Использовать assets/edp-logo-dark.svg на Dark и assets/edp-logo-light.svg на Paper/White. PNG для Office; mark — для компактных форматов. Не растягивать. Охранное поле 1/4 высоты знака.
- Палитра: brand-tokens.json. Lime только для акцентов на Dark или заливок с Ink. Светлый фон Paper / White, текст Ink, акценты Green.
- Arial — основной шрифт; Consolas — технические метки.
- PPTX: 16:9, поля 0,6 дюйма, один тезис на слайд, 2–3 колонки; титул и разделы Dark, основной контент Paper.
- DOCX: A4, поля 20 мм, Arial 11–12 pt, интервал 1,15; логотип сверху, версия и номер страницы снизу.
- Графики: подписывать источник, период, единицы измерения; не кодировать смысл только цветом.
- Тон: инженерный, деловой, конкретный. EDP — референсная архитектура, не заявлять коммерческую готовность и неподтвержденные KPI/SLA.
- Перед выпуском: проверить контраст, версию, ссылки, рендер PDF и отсутствие заполнителей.

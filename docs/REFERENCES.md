# Архитектурные и визуальные референсы

- AXIVO: https://github.com/axivo/website — Next.js, React, Nextra, Tailwind, Cloudflare. Из README и package.json. В EDP использованы общие принципы, без заимствования кода.
- Arenadata: https://arenadata.tech/ru — продуктовая подача, каталог возможностей, референсная схема, сценарии, блок надёжности, FAQ. В EDP оригинальные тексты, палитра и SVG.

MVP не является форком. Для дальнейшего копирования кода AXIVO отдельно проверьте условия BSD-3-Clause, включая сохранение уведомлений об авторских правах. Не заимствуйте бренд и визуальные активы Arenadata.

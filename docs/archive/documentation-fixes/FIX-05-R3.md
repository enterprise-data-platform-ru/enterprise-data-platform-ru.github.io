# FIX-05-R3 — Единое выравнивание контента документации

## Проблема

На страницах /docs/ и /docs/overview/ различается горизонтальный отступ между Sidebar и основным контентом.

Предполагаемая причина: margin-inline: auto у контейнеров .docs-article и .docs-catalog с различной максимальной шириной.

## Задача

В файле src/app/docs/docs.css найти:

```css
.docs-article, .docs-catalog {
  width: 100%;
  min-width: 0;
  margin-inline: auto;
  overflow-wrap: break-word;
}
```

Заменить на:

```css
.docs-article, .docs-catalog {
  width: 100%;
  min-width: 0;
  margin-inline: 0 auto;
  overflow-wrap: break-word;
}
```

Сохранить:

- Максимальную ширину статьи 820px.
- Максимальную ширину каталога 1100px.
- Существующие padding контейнера .docs-main.
- Адаптивные breakpoints.
- Существующую ширину Sidebar и TOC.

## Критерии приёмки

- Breadcrumbs начинаются на одной вертикальной линии.
- Заголовки H1 начинаются на одной вертикальной линии.
- При переходе между каталогом и статьёй контент не смещается горизонтально.
- Sidebar не изменяет ширину при одинаковом viewport.
- Отсутствует горизонтальное переполнение.
- Сохраняется адаптивность.

Проверить обе страницы при одинаковом размере viewport и масштабе браузера 100%.

Выполнить npm test и git diff --check.

Обновить docs/IMPLEMENTATION-STATE.md.

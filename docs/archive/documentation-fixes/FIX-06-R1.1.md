# FIX-06-R1.1 — Sidebar Sticky Refinement

## Цель

Исправить позиционирование и поведение левой панели навигации документации.

## Ограничения

- Прочитай AGENTS.md.
- Не загружай весь репозиторий в контекст.
- Изучай только файлы, необходимые для текущего задания.
- Не добавляй зависимости.
- Не переходи к следующим заданиям.
- Не выполняй git commit и git push.

## Область изменений

- src/app/docs/docs.css
- src/components/DocsSidebar.jsx — при необходимости.
- tests/docs-layout.test.mjs
- docs/IMPLEMENTATION-STATE.md
- Файлы демонстрационной страницы.

## Требования

1. При ширине экрана от 900px Sidebar должен использовать sticky-позиционирование.
2. Верхняя граница определяется через var(--docs-header-height).
3. Высота рассчитывается относительно доступной высоты viewport.
4. Sidebar должен иметь независимую вертикальную прокрутку.
5. При ширине менее 900px Sidebar возвращается в обычный поток документа.
6. Заголовки групп навигации должны иметь компактное оформление.
7. Минимальная высота ссылок — 36px, для coarse pointer — 44px.
8. Сохранить details/summary, активную группу, aria-current и focus-visible.
9. Не реализовывать мобильный drawer — это отдельное задание FIX-07.

## Демонстрационная страница

Создай страницу:

/docs/style-preview/fix-06-r1-1/

Страница должна использовать реальные DocsLayout и DocsSidebar, существующие стили и достаточно длинный демонстрационный контент.

Обеспечь возможность визуальной проверки:

- Sticky-позиционирования Sidebar.
- Независимой прокрутки навигации.
- Активных пунктов меню.
- Раскрытия групп.
- Положения Sidebar относительно Header и Footer.
- Поведения при ширине 1440, 1024, 900, 899, 768 и 390px.

Добавь на страницу краткое описание проверяемых сценариев и ожидаемого поведения.

Не создавай копии production-компонентов.

Демонстрационную страницу не включай в основную навигацию и sitemap. Установи noindex, используя существующий механизм метаданных проекта.

# FIX-06-R1.2 — TOC Layout and Styling

## Цель

Исправить расположение, адаптивность и визуальное оформление оглавления документации.

## Ограничения

- Прочитай AGENTS.md.
- Сохрани изменения предыдущего задания.
- Изучай только необходимые файлы.
- Не добавляй зависимости.
- Не изменяй алгоритм ScrollSpy.
- Не выполняй git commit и git push.

## Область изменений

- src/app/docs/docs.css
- src/components/DocsToc.jsx
- src/components/DocsLayout.jsx — при необходимости.
- tests/docs-layout.test.mjs
- docs/IMPLEMENTATION-STATE.md
- Файлы демонстрационной страницы.

## Требования

1. При ширине от 1200px TOC располагается справа и использует sticky-позиционирование.
2. Ширина правой колонки — 224px.
3. При ширине 900–1199px TOC располагается перед статьёй и поддерживает сворачивание через details/summary.
4. При ширине менее 900px TOC находится в основном потоке документа перед статьёй.
5. Использовать только один экземпляр DocsToc.
6. Активный пункт оформляется через aria-current="location".
7. Добавить визуальное выделение активного пункта, левый индикатор и отступ для H3.
8. Обеспечить focus-visible.
9. Страница /docs/ должна оставаться двухколоночным каталогом без TOC.

## Демонстрационная страница

Создай страницу:

/docs/style-preview/fix-06-r1-2/

Используй реальные DocsLayout и DocsToc.

Добавь длинную демонстрационную статью, содержащую не менее восьми H2 и нескольких вложенных H3.

Страница должна демонстрировать:

- Правую колонку TOC на desktop.
- Sticky-позиционирование.
- Иерархию H2/H3.
- Оформление активного пункта.
- Сворачиваемое оглавление.
- Перемещение TOC в основной поток.
- Отсутствие горизонтальной прокрутки.

Добавь описание ожидаемого поведения для ширины 1440, 1200, 1199, 1024, 900, 899, 768 и 390px.

Не имитируй работу TOC отдельным компонентом.

Не включай страницу в основную навигацию и sitemap. Установи noindex.

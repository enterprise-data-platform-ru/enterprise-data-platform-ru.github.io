# FIX-06-R1.3 — ScrollSpy Core Algorithm

## Цель

Исправить алгоритм определения активного заголовка документации.

## Ограничения

- Прочитай AGENTS.md.
- Не изменяй production-компоненты React и CSS.
- Не добавляй зависимости.
- Сохрани изменения предыдущих заданий.
- Не выполняй git commit и git push.

## Область изменений

- src/lib/scroll-spy.mjs
- tests/scroll-spy.test.mjs
- docs/IMPLEMENTATION-STATE.md
- Изолированные файлы демонстрационной страницы.

## Требования

Используй существующую функцию findActiveHeading.

По возможности сохрани её публичный API.

Алгоритм должен корректно обрабатывать:

1. Пустой список заголовков.
2. Один заголовок.
3. Положение страницы до первого заголовка.
4. Пересечение порога активации.
5. Переходы между H2 и H3.
6. Несколько пройденных заголовков.
7. Прокрутку до конца страницы.
8. Короткую страницу.
9. Страницу без возможности прокрутки.
10. Обратную прокрутку.
11. Граничные значения.

Покрой сценарии unit-тестами.

## Демонстрационная страница

Создай страницу:

/docs/style-preview/fix-06-r1-3/

Реализуй изолированный диагностический стенд для визуальной проверки findActiveHeading.

Стенд должен импортировать и вызывать реальную функцию из src/lib/scroll-spy.mjs.

Для каждого сценария отображай:

- Входные параметры.
- Позиции заголовков.
- Положение порога активации.
- Ожидаемый активный заголовок.
- Фактический результат.
- Статус PASS или FAIL.

Дополнительно реализуй простой интерактивный сценарий с изменением виртуальной позиции прокрутки и отображением текущего активного заголовка.

Для интерактивности допускается небольшой изолированный Client Component.

Не дублируй алгоритм ScrollSpy внутри демонстрационной страницы.

Не изменяй production-интеграцию ScrollSpy — это следующее задание.

Не включай страницу в основную навигацию и sitemap. Установи noindex.

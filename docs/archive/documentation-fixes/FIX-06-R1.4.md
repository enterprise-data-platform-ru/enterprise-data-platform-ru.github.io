# FIX-06-R1.4 — ScrollSpy React Integration and Anchors

## Цель

Интегрировать исправленный алгоритм ScrollSpy с компонентами документации и обеспечить корректную работу якорных ссылок.

## Ограничения

- Прочитай AGENTS.md.
- Используй результаты FIX-06-R1.1, R1.2 и R1.3.
- Не добавляй зависимости.
- Не изменяй архитектуру документации.
- Не выполняй git commit и git push.

## Область изменений

- src/components/DocsToc.jsx
- src/components/DocsLayout.jsx — при необходимости.
- Целевые тесты.
- docs/IMPLEMENTATION-STATE.md
- Файлы демонстрационной страницы.

## Требования

1. Использовать существующую функцию findActiveHeading.
2. Определять H2 и H3 внутри article#docs-content.
3. Измерять положение самого заголовка, даже если id находится на вложенном anchor.
4. Учитывать высоту Header и дополнительный отступ 24px.
5. Использовать requestAnimationFrame для обработки scroll.
6. Использовать passive scroll listener.
7. Обрабатывать resize, hashchange и переходы по ссылкам TOC.
8. Корректно освобождать listeners и pending requestAnimationFrame.
9. Не обновлять React state, если активный заголовок не изменился.
10. Поддерживать прямой переход по URL с hash.
11. Поддерживать browser back/forward.
12. Корректно обрабатывать короткие статьи.
13. Не изменять hash при обычной прокрутке.
14. Сохранить существующие опубликованные anchors.
15. Только один пункт TOC должен иметь aria-current="location", если в статье есть заголовки.

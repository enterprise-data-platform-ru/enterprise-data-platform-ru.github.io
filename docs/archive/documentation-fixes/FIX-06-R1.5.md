# FIX-06-R1.5 — Integration, Regression and Acceptance

## Цель

Провести комплексную проверку результатов FIX-06-R1.1 — FIX-06-R1.4 и подготовить реализацию к приёмке.

## Ограничения

- Прочитай AGENTS.md.
- Изучи записи предыдущих заданий в IMPLEMENTATION-STATE.md.
- Не загружай весь репозиторий в контекст.
- Исправляй только небольшие дефекты в рамках FIX-06.
- Существенные проблемы фиксируй как отдельные follow-up задачи.
- Не переходи к FIX-07.
- Не выполняй git commit и git push.

## Автоматизированная проверка

1. npm test.
2. Production build с пустым NEXT_PUBLIC_BASE_PATH.
3. Проверка статического экспорта через существующий check:export.
4. Build с NEXT_PUBLIC_BASE_PATH=/edp-test.
5. Повторная проверка статического экспорта.
6. Восстановление production export с пустым base path.
7. git diff --check.
8. git diff --stat.
9. git status.

Проверь наличие опубликованных anchors в экспортированном HTML.

## Функциональная и визуальная проверка

Проверь:

- /docs/
- /docs/overview/
- Все демонстрационные страницы FIX-06.

Используй ширину viewport:

- 1920px
- 1440px
- 1200px
- 1199px
- 1024px
- 900px
- 899px
- 768px
- 390px

Проверь Sidebar, TOC, ScrollSpy, Header, Footer, keyboard navigation, anchors, отсутствие горизонтальной прокрутки, hydration warnings и ошибок JavaScript.

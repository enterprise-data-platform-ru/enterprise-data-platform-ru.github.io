## 5. FIX-06-R1.1 — Высота и оформление Sidebar

### Проблема

Sidebar должна занимать всю доступную высоту под глобальным sticky Header независимо от количества пунктов навигации.

### Требования

При viewport от 900px:

- position: sticky.
- top: var(--docs-header-height).
- Высота доступной области окна.
- align-self: start.
- Независимая вертикальная прокрутка.
- Фон и правая граница заполняют всю высоту панели.
- Sidebar не перекрывает Header и Footer.

Целевые CSS-свойства:

```css
.docs-sidebar {
  position: sticky;
  top: var(--docs-header-height);
  align-self: start;
  height: calc(100dvh - var(--docs-header-height));
  min-width: 0;
  overflow-y: auto;
  overscroll-behavior-y: contain;
}
```

Адаптировать существующее правило, сохранив оформление FIX-05 и FIX-06.

При viewport до 899px:

```css
.docs-sidebar {
  position: static;
  height: auto;
  max-height: none;
  overflow: visible;
}
```

Сохранить:

- Desktop Sidebar: 256px.
- Tablet Sidebar: 224px.
- Background: var(--docs-sidebar-bg).
- Padding: 24px 16px.
- Нативные details/summary.
- Раскрытие группы активной статьи.
- aria-current="page".
- Ссылки только на опубликованные документы.

Для .docs-nav-summary:

- Font-size: 11px.
- Text-transform: uppercase.
- Font-weight: 600.
- Видимый focus-visible.
- Минимальная высота: 36px.

Для ссылок и элементов раскрытия на устройствах с сенсорным вводом минимальная высота должна составлять 44px.

Использовать подходящий media query для pointer: coarse.

Не реализовывать мобильный Drawer.

## 6. FIX-06-R1.2 — Оформление TOC

Использовать aria-current="location" как единственный источник визуального состояния активной ссылки.

Целевой стиль:

```css
.docs-toc-list a {
  display: block;
  padding: 6px 8px;
  border-left: 3px solid transparent;
  font-size: 13px;
  line-height: 20px;
  color: var(--docs-muted);
  text-decoration: none;
  overflow-wrap: anywhere;
}

.docs-toc-list a[aria-current="location"] {
  border-left-color: var(--docs-primary);
  color: var(--docs-primary);
  font-weight: 600;
}
```

Сохранить существующий фон активного элемента, если он уже соответствует дизайн-системе.

Удалить дублирующие CSS-правила и класс is-active из TOC, только если они больше нигде не используются.

Не удалять is-active из Sidebar без проверки его использования.

Сохранить:

- Вложенность H3: 12px.
- Видимый клавиатурный фокус.
- Существующие цвета.
- Перенос длинных названий.
- Отсутствие горизонтального переполнения.

В непустом видимом TOC ровно одна ссылка должна иметь aria-current="location".

## 8. FIX-06-R1.4 — Алгоритм ScrollSpy

Основные файлы:

```text
src/components/DocsToc.jsx
src/lib/scroll-spy.mjs
```

Использовать существующую функцию findActiveHeading.

Не создавать альтернативный алгоритм.

Источник заголовков:

```text
article#docs-content
```

Учитывать только H2 и H3 в порядке их расположения в статье.

Для определения позиции использовать сам элемент H2 или H3, даже если идентификатор находится на вложенном a[id].

### Линия активации

Использовать фактическую высоту .site-header либо синхронизированное значение --docs-header-height плюс 24px.

Учитывать существующие scroll-padding-top и scroll-margin-top.

Не добавлять повторную компенсацию полной высоты Header.

### Правила выбора активного заголовка

1. При отсутствии заголовков активный идентификатор отсутствует.
2. До достижения первого заголовка активен первый пункт.
3. При прокрутке активен последний заголовок, прошедший линию активации.
4. При достижении низа прокручиваемой страницы активен последний заголовок.
5. На непрокручиваемой странице не активировать последний пункт только потому, что scrollHeight равен clientHeight.
6. При прокрутке вверх активный пункт корректно возвращается к предыдущему разделу.

Вычисление активного заголовка должно оставаться детерминированным и пригодным для unit-тестирования.

## 10. FIX-06-R1.6 — Якорная навигация

Сохранить существующие опубликованные якоря:

```text
/docs/overview/#naznachenie
/docs/overview/#granitsy
```

Сохранить наличие этих идентификаторов в статическом HTML.

Для внутренних ссылок использовать:

```jsx
href={`#${id}`}
```

Не использовать linkHref() для локальных якорей.

При прямой загрузке URL с валидным hash соответствующий пункт TOC должен становиться активным.

При клике по ссылке TOC активировать выбранный раздел, даже если высоты документа недостаточно для прокрутки заголовка до линии активации.

Не допускать, чтобы обработчик программной прокрутки немедленно сбрасывал выбранный пункт.

После завершения якорного перехода и последующей ручной прокрутки снова определять активный раздел по позиции заголовков.

Проверить:

- Валидный hash.
- Несуществующий hash.
- Кириллические идентификаторы.
- Явные идентификаторы.
- Вложенные a[id].
- Повторяющиеся заголовки.
- Переходы браузера назад и вперёд.
- Короткую статью.
- Длинную статью.

Не переименовывать существующие уникальные идентификаторы.

# Обзор платформы

Краткое описание назначения, границ и ключевых решений корпоративной
платформы данных. Раздел отвечает на вопросы: для каких сценариев
предназначена платформа, какие уровни она покрывает и какие технологические
решения лежат в её основе.

## Назначение

- Сокращение времени на внедрение и масштабирование обработки данных.
- Единая логическая архитектура для on-premises, облачного и гибридного
  размещения.
- Чёткие границы ответственности между уровнями и модулями.

## Границы

Платформа описана как референсная архитектура на основе открытых
технологий. Конкретные компоненты и их версии выбираются под требования
проекта.

> Материал находится в работе и будет расширяться по мере готовности
> смежных разделов.

# Проверка расположения оглавления

Проверьте оглавление, индикатор активного пункта и фокус клавиатуры. На 1440 и 1200 px оглавление закреплено справа; на 1199, 1024 и 900 px оно сворачивается перед статьёй; на 899, 768 и 390 px находится в потоке. Горизонтальной прокрутки страницы быть не должно.

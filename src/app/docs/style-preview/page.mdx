## 2. Абзацы и текстовое форматирование

Короткий абзац.

Длинный абзац с **жирным текстом**, *курсивом*, ***жирным курсивом*** и ~~зачёркнутым текстом~~. При чтении инженерной документации важно сохранять комфортную длину строки, стабильный межстрочный интервал и одинаковые отступы между абзацами. При изменении ширины окна текст должен переноситься без горизонтальной прокрутки страницы.

Встроенный код: `SELECT * FROM data`, `--namespace`, `NEXT_PUBLIC_BASE_PATH`, `const x = 42;`.

Клавиатурные сочетания: <kbd>Ctrl</kbd> + <kbd>C</kbd>, <kbd>Tab</kbd>, <kbd>Enter</kbd>, <kbd>Esc</kbd>.
